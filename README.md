# PhysioFit 🏋️‍♂️

**PhysioFit** is a web and AR-assisted physical therapy assistant designed to help patients perform exercises correctly under physiotherapist supervision. It allows physiotherapists to monitor patient progress and patients to follow guided exercise routines safely.

## Key Features

1. **Exercise Tracking**  
   - Patients can follow prescribed exercises and log their activity.  
   - Tracks repetitions, sets, and duration.

2. **Patient Login**  
   - Secure access to personal exercise plans.  
   - View assigned physiotherapist details.

3. **Physiotherapist Login**  
   - Access assigned patient data.  
   - Monitor patient exercise performance in real-time.

4. **AR Exercise Assistance**  
   - Uses **Mediapipe** to track patient movements via camera.  
   - Provides real-time feedback for proper form and technique.

## Tech Stack

- **Frontend:** React JS  
- **Backend:** Flask API  
- **Computer Vision/AR:** Mediapipe, OpenCV  
- **Database:** Firebase
